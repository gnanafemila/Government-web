# Government Scheme Portal

## About the Project

The **Government Scheme Portal** is a web-based application designed to provide citizens with information about various government schemes. It helps users explore available schemes, check their eligibility, register, and track their application status.

The main objective of this project is to make government scheme information easier to access and understand.

## Features

- **Scheme Information:** Provides details about available government schemes.
- **User Registration:** Allows users to register on the portal.
- **Eligibility Checker:** Helps users check whether they meet the eligibility criteria for schemes.
- **Application Status Tracking:** Allows users to track the status of their applications.
